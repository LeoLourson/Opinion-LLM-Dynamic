### Основная порция A+B, повтор 0 — 12 октября 2026

Пользователь поручил запуск предложенных 20 уникальных диалогов Luna → DeepSeek.
План: runs/v2/plans/luna_deepseek_AB_repeat0.json (15 стратегий и 5 дополнительных
социальных вариантов, общий базовый контроль). Опрос и калибровка уже завершены.
Конфигурация сохранена: gpt-6-luna / reasoning_effort=low → deepseek-flash;
контраргумент deepseek-flash. Повторы 1–4 не входят в порученный запуск.

Root единолично управляет состояниями и API-шагами. Технический participant_launcher
читает participant.md, назначенные request-файлы и очереди AB_launch_batch*.json,
создаёт свежих участников Luna с fork_turns=none, сохраняет дословные конверты
answers/ и реальные метаданные запуска launches/. Он не вызывает API и не изменяет
состояния опытов. Каждый экспериментальный участник получает только полный
participant.md и один request; файлы проекта и приватные замеры ему не передаются.

Локальный помощник runs/v2/ab_session.py исполняет цикл root, проверяет совпадение
execution с метаданными запуска и профилем перед submit. Отдельная техническая
сессия запуска не является участником или экспериментальным наблюдением.
Начальные ответы API получены для всех20 опытов. Выполнение продолжается.

Порция не завершена и удалена по поручению пользователя 12 октября 2026: все 20
диалогов стояли на ходе атакующего (раунды 1–2). Удалены их состояния, запросы,
ответы, метаданные запусков, очереди AB_launch_batch*.json, планы A/B повтора 0
и AB_repeat0_usage_baseline.json. Опрос, калибровка и проба Luna сохранены.
Ответы API этой порции остались в requests.sqlite3 и входят в общий счёт.
Помощники runs/v2/ab_session.py и ab_report.py оставлены; они ссылаются на
удалённый план.
